최초 1회 설정이 필요해요

1. Firebase 콘솔에서 새 프로젝트 만들기 (구글 계정만 있으면 무료)
2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기

4. 만들어진 후 Rules 탭에서 규칙을 아래처럼 바꾸고 게시(Publish):
{ "rules": { ".read": true, ".write": true } } 5. Realtime Database 페이지 상단에 보이는 주소(https://xxxx-default-rtdb.xxxx.firebasedatabase.app 형태)를 복사
6. 코드 안의 FIREBASE_DB_URL = 'REPLACE_ME' 부분의 REPLACE_ME 자리에 그 주소를 붙여넣고 저장 후 다시 올리기
